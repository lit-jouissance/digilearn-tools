# 우리 반 학습도구 — 설치 · 사용 안내

한 파일(`index.html`)로 된 수업용 웹앱이에요. 학습도구 **28개**가 들어 있고, **모든 도구에 저장 기능**이 있어요.
Firebase에 저장하고 Vercel에 올리면, 선생님은 Google 계정으로 로그인해 자기 활동을 관리하고, 학생들은 **로그인 없이 QR로** 들어와 참여해요.

- 예시 주소: `https://digilearn-tools.vercel.app`
- 이 안내서는 **A. 처음 설치(관리하는 선생님)** → **B. 선생님 사용법** → **C. 도구별 사용법** → **D. 문제 해결** 순서예요.
- 다른 선생님께는 **B**부터 보여 드리면 돼요.

| 묶음 | 도구 | 학생과 함께할 때 |
|---|---|---|
| 🧩 생각 정리 | 만다라트, 마인드맵, 벤다이어그램, KWL 표, 피시본, 이야기 지도 | 학생이 각자 채워서 **제출** → 선생님이 제출물 확인 |
| 💡 깊이 생각하기 | 주장·근거·이유, 보고·생각하고·궁금해하기, 생각 바뀜 기록, 찬반 토론판 | 제출물 **한눈에 보기** 표 / 토론판은 실시간 |
| 📡 수업 참여 | 실시간 투표, 출구 카드, 생각 온도계, 워드클라우드, 담벼락 | 학생 응답이 선생님 화면에 **실시간**으로 모임 |
| 👥 모둠 활동 | 랜덤 뽑기·모둠 짜기, 돌림판, 타이머 | 교사 화면용 (설정만 저장). 돌림판·뽑기에 효과음(🔊 끄기 가능), 타이머에 현재 시각과 끝나는 시각 |
| 📝 받아쓰기 · 바른 글씨 | 받아쓰기(회차당 10문제), 영어 단어·구동사(회차당 15개), 바른 글씨 쓰기 | 받아쓰기는 교사 화면용 / 바른 글씨는 학생이 따라 쓰고 제출 |
| 🔁 정리 · 복습 | 낱말 카드, 빙고판, 순서 맞추기 | 학생이 각자 공부·풀이 (빙고·순서는 제출 가능) |
| 📒 기록 · 평가 | 학습 일지, 루브릭 자기평가 | 학생이 각자 작성해서 **제출** |
| 🏫 학급 생활 | 알림장, 명상 | 알림장은 학생이 QR로 보고 체크 / 명상은 교사 화면 |

# A. 처음 설치 (관리하는 선생님, 한 번만)

## A-1. Firebase 준비 (약 10분)

1. **프로젝트 만들기**: [Firebase 콘솔](https://console.firebase.google.com)에서 새 프로젝트를 만들어요. 기존 프로젝트를 써도 돼요.
2. **웹 앱 추가**: 프로젝트 설정(⚙️) → 일반 → 내 앱 → 웹(`</>`) 추가 → 나오는 `firebaseConfig` 값을 복사해요.
3. **설정값 붙여 넣기**: `index.html`을 메모장이나 VS Code로 열어, 위쪽 `window.FIREBASE_CONFIG = { ... }` 칸에 붙여 넣고 저장해요.
   - 이 값은 공개되어도 괜찮은 값이에요. 실제 보호는 보안 규칙(A-1의 6번)이 해요.
   - ⚠️ 새 `index.html`을 받을 때마다 이 설정값을 **다시 넣어야** 해요.
4. **로그인 방법 켜기**: 왼쪽 **Authentication(인증)** → 위쪽 **Sign-in method(로그인 방법)** 탭 → **Add new provider(새 제공업체 추가)**
   - **Google** → **Enable(사용 설정)** 켜기 → **Project support email(프로젝트 지원 이메일)**에서 내 Gmail 고르기 → **Save** ← 선생님용
   - **Anonymous(익명)** → **Enable** 켜기 → **Save** ← 학생용
   - 프로젝트 지원 이메일은 로그인 창에 보이는 **연락처일 뿐**이에요. 여기에 내 이메일을 넣어도 다른 선생님들은 그대로 로그인할 수 있어요.
5. **Firestore 만들기**: **Firestore Database** → 데이터베이스 만들기 → 위치 `asia-northeast3 (서울)` 추천 → 프로덕션 모드.
6. **보안 규칙 붙여 넣기**: Firestore → **규칙** 탭에 `firestore.rules` 내용을 통째로 붙여 넣고 **게시**해요.

### 누가 '선생님'으로 쓸 수 있게 할까요?

- **기본(그대로 두기)**: Google 계정이 있는 선생님이면 **누구나** 로그인해서 저장·공유할 수 있어요. 다른 학교·학년 선생님들과 나눠 쓰기에 좋아요.
- **정한 선생님만**: `firestore.rules` 안의 아래 줄에서 `//`를 지우고 이메일을 적은 뒤 **게시**해요. 목록에 없는 사람은 로그인은 되지만 저장·공유가 막혀요.

  ```
  && request.auth.token.email in ['moon@gmail.com', 'kim@gmail.com', 'lee@gmail.com']
  ```

  새 선생님이 오시면 이 목록에 이메일을 더하고 다시 **게시**하면 돼요.

## A-2. Vercel에 올리기

### 방법 1. Vercel Drop (가장 쉬움, GitHub 필요 없음)

1. 바탕화면에 폴더(예: `digilearn-tools`)를 만들고, 압축을 푼 파일을 **모두** 넣어요: **설정값을 넣은** `index.html`, `manifest.webmanifest`, `sw.js`, `icons` 폴더. (이 세 가지가 있어야 '앱 설치'가 돼요)
2. 로그인한 상태로 **vercel.com/drop**에 들어가요.
3. **폴더째** 화면에 끌어다 놓아요. (index.html 하나만 올리면 앱 설치가 안 돼요)
4. 팀(Hobby)을 고르고 프로젝트 이름(예: `digilearn-tools`)을 적은 뒤 **Deploy**를 눌러요.
5. 완료 화면의 주소(**Visit**)를 눌러 첫 화면이 열리는지 확인해요.

**앱을 고쳐 다시 올릴 때**: 드롭할 때마다 새 프로젝트가 만들어져요. 같은 주소를 유지하려면 이렇게 해요.
1. Vercel 대시보드에서 기존 프로젝트 → **Settings** → 맨 아래 **Delete Project**로 지워요.
2. 새 파일들(설정값 넣은 `index.html` 포함)이 든 폴더를 **같은 이름**으로 다시 드롭해요.

저장한 활동과 학생 응답은 Firebase에 있어서 다시 올려도 그대로 남아요.

### 방법 2. GitHub + Vercel (자주 고칠 때 추천)

1. github.com → **＋ → New repository** → 이름(예: `digilearn-tools`) → **Create repository**를 눌러요.
2. **Add file → Upload files** → `index.html`을 끌어다 놓고 **Commit changes**를 눌러요. 파일은 폴더 안이 아니라 **맨 위**에 있어야 해요.
3. vercel.com → **Add New → Project** → 그 저장소 **Import** → Framework Preset **Other** → **Deploy**를 눌러요.
4. 고칠 때는 GitHub에 새 `index.html`을 같은 이름으로 올리고 **Commit**만 하면, 같은 주소로 자동 반영돼요.

## A-3. Firebase에 앱 주소 등록 (꼭!)

Firebase 콘솔 → **Authentication** → **Settings(설정)** 탭 → **Authorized domains(승인된 도메인)** → **Add domain(도메인 추가)**
- `digilearn-tools.vercel.app`처럼 **`https://`와 끝의 `/`를 뺀 주소**만 적어요.
- 안 하면 선생님 로그인 때 `auth/unauthorized-domain` 오류가 나요.

## A-4. 설치 확인

1. 앱 주소에 들어가 오른쪽 위 **선생님 로그인**을 눌러요.
2. 오른쪽 위가 **'선생님 · 내 이메일'**로 바뀌는지 봐요.
3. 아무 도구에서나 **저장**을 눌러 **'저장됨'**이 뜨는지 봐요.
4. **📱 학생과 함께하기**로 QR을 띄우고 휴대폰으로 찍어 학생 화면이 열리는지 봐요.

# B. 선생님 사용법 (다른 선생님께 이 부분을 알려 주세요)

## B-1. 내 계정으로 로그인하기

1. 앱 주소를 **크롬, 엣지, 사파리**로 열어요.
2. 오른쪽 위 **선생님 로그인** → 내 Google 계정을 골라요.
3. 오른쪽 위가 **'선생님 · 내 이메일'**로 바뀌면 끝이에요.

- 선생님마다 **저장 목록이 따로**예요. 다른 선생님의 활동이나 그 반 학생 응답은 서로 보이지 않아요.
- 같은 계정으로 로그인하면 **집 컴퓨터, 교실 PC, 태블릿 어디서든** 내 저장 목록을 열 수 있어요.
- 여러 사람이 쓰는 교실 PC라면 수업 뒤 **로그아웃**을 눌러 주세요.
- 로그인하지 않으면 오른쪽 위에 **'이 기기에 저장'**이 보이고, 그 브라우저에만 저장돼요. 로그인해도 계정으로 자동으로 옮겨지지 않으니 **처음부터 로그인하고** 쓰세요.

### 로그인이 안 될 때
- **카카오톡에서 링크를 열었을 때**: 카카오톡 안 브라우저에서는 Google 로그인이 막혀요. **⋮ → 다른 브라우저로 열기**를 눌러요.
- **아무 창도 안 뜰 때**: 팝업이 차단된 거예요. 주소창 오른쪽 팝업 차단 표시를 눌러 **허용**해요.
- **학교·교육청 Google 계정**: 외부 앱 로그인이 제한된 경우가 있어요. 개인 Gmail로 로그인해요.
- 오류 코드가 보이면 **D. 문제 해결**을 봐요.

## B-1-1. 컴퓨터에 앱으로 설치하기 💻

설치하면 바탕 화면·작업 표시줄(맥은 Dock)에 '우리반' 아이콘이 생기고, 주소창 없이 앱 창으로 열려요.

- **크롬·엣지·웨일(윈도우, 맥, 크롬북)**: 앱 주소를 열고 오른쪽 위 **💻 앱 설치** 단추를 눌러 **설치**. 주소창 오른쪽 끝의 설치 아이콘이나 ⋮ 메뉴 → **앱 설치**로도 돼요.
- **맥 사파리**: 메뉴 **파일 → Dock에 추가**.
- **아이패드·아이폰 사파리**: 공유 단추 ⬆︎ → **홈 화면에 추가**.
- 설치한 앱도 같은 주소의 같은 앱이라, 로그인·저장한 활동이 그대로예요. 새 버전을 올리면 앱을 다시 열 때 자동으로 바뀌어요.
- 인터넷이 잠깐 끊겨도 첫 화면은 열리지만, 저장·학생 참여는 인터넷이 있어야 해요.
- 지우려면 앱 창 오른쪽 위 ⋮ 메뉴 → **제거**.
- 학생들은 설치하지 않아도 돼요. QR·링크로 그대로 참여해요.

## B-2. 수업에서 쓰는 순서

1. **첫 화면**에서 묶음 색깔별로 도구를 골라요.
2. 내용을 만들고 **저장** → 다음에도 **저장 목록**에서 열 수 있어요.
3. **📱 학생과 함께하기** → QR이 나와요. **크게 띄우기**로 TV에 띄우면 학생들이 카메라로 찍고 들어와요. 활동을 고친 뒤에는 **저장**해야 학생 화면에도 반영돼요.
4. 학생은 위쪽에 **이름(번호)**을 적고 참여해요.
   - 투표·온도계·출구 카드·담벼락·워드클라우드·토론판: 누르는 즉시 선생님 화면에 모여요.
   - 만다라트 같은 개별 활동: 다 쓰고 **선생님께 제출하기** → 선생님은 **제출물 (n)**에서 한 명씩 열어 봐요. 일부 도구는 **한눈에 보기** 표도 나와요.
   - 학생이 쓰던 내용은 학생 기기에 자동 보관돼요.
5. 투표·생각 온도계는 **👀 학생 화면에 보여 줄 결과**에서 '보여 주지 않기 / 가로 막대 / 세로 막대 / 꺾은선 / 원그래프' 중 하나를 골라요. 선생님 화면 그래프는 결과 위 단추로 따로 바꾸고, **누가 골랐는지 보기**는 선생님 화면에만 나와요.

## B-2-1. 학생 기록 보기와 엑셀로 내려받기 📥

- **개인 활동(만다라트, 생각 바뀜 기록, 이야기 지도 등)**: 학생이 **선생님께 제출하기**를 눌러야 선생님 화면의 **제출물 (n)**에 모여요. 학생 화면의 자동 저장은 학생 기기에만 남는 '임시 저장'이라 선생님은 볼 수 없어요.
- **제출물** 창에서 '한눈에 보기' 표, 한 명씩 보기, **📥 엑셀로 내려받기 (CSV)**를 쓸 수 있어요.
- **실시간 활동(투표, 출구 카드, 온도계, 워드클라우드, 담벼락, 토론판)**: 위 막대의 **📥 기록 내려받기**로 이름·시각·응답을 받아요.
- 평가 자료로 쓸 때: 학생 이름은 학생이 직접 적는 것이라, 처음에 **'번호 이름'(예: 3 김민지)**으로 적도록 약속해 두면 정리하기 쉬워요.

## B-2-2. 선생님 도구 (기록 · 평가 묶음, 수업 참여 묶음)

- **👥 우리 반 명단**: 관찰 기록·체크표·성장 기록 위쪽에 "번호 이름"으로 한 번 적어 두면, 다른 도구에서는 **📋 다른 도구의 명단 불러오기**로 가져와요. 학생이 적는 이름과 같게 적어야 기록이 잘 모여요.
- **👀 관찰 기록**: 날짜, 학생(여럿 선택 가능), 영역(수업 참여·협력·생활·성취·기타), 구분(👍 칭찬 / 👀 관찰 / 🤝 도움 필요)을 고르고 한두 줄 적어요. 저절로 저장돼요. '학생별 기록 수'에서 기록이 없는 학생이 분홍색으로 보여요. 엑셀로 내려받을 수 있어요.
- **✅ 과제 · 준비물 체크표**: 과제·준비물을 추가하고 칸을 누르면 ✅ 냈어요 → ❌ 안 냄 → ⏰ 늦게 냄 → 빈칸으로 바뀌어요. '🔔 아직 안 낸 학생'에서 바로 확인해요. 저절로 저장돼요.
- **🌱 학생 성장 기록**: **🔄 모든 활동에서 기록 모으기**를 누르면 선생님이 저장한 모든 활동의 학생 제출·응답, 관찰 기록, 과제 기록이 학생별로 모여요. 학생을 골라 기록을 보고, 선생님 메모를 남기고(저장 단추), 학생별·전체 엑셀 내려받기나 인쇄(상담 자료)를 해요. 명단에 없는 이름(점선)은 학생이 이름을 다르게 적은 경우예요.
- **🏆 실시간 퀴즈 대회**: OX·객관식 문제와 정답, 제한 시간을 만들고 저장 → 📱 학생과 함께하기. 학생이 이름을 적고 들어오면 '들어온 학생' 수가 보여요. **▶ 퀴즈 시작 → (시간이 끝나면) 💡 정답 공개 → ▶ 다음 문제 → 🏆 결과 발표** 순서예요. 빨리 맞힐수록 점수가 높아요(정답 100점 + 빠르기 최대 50점). 문제별 정답률로 다시 짚을 문제를 찾고, 📥 기록 내려받기로 답을 엑셀로 받아요.

- **🙋 발표 기회 고르게**: 명단을 불러오면 이름 칸이 생겨요. 발표할 때마다 이름을 누르면 횟수가 쌓이고, 칸 색이 진해져요(잘못 누르면 ↶ 방금 것 취소). **🎲 덜 한 친구 중에서 뽑기**는 오늘·이번 주·전체 중 고른 기간에서 **가장 적게 발표한 학생들 가운데**서만 뽑아요. 저절로 저장돼요.
- **🧹 1인 1역 역할표**: '역할 | 하는 일'을 한 줄에 하나씩 적어요(＋ 예시 역할 넣기). **다음 주로 돌리기 ▶**를 누르면 모두 한 칸씩 다음 역할로 옮겨 가요. ◀로 되돌리고, 🔀로 처음 순서를 섞어요. 역할보다 학생이 많으면 한 역할을 여럿이 맡아요.
- **🪑 자리 바꾸기**: 줄·칸 수와 짝 앉기를 정하고, '앞자리 학생', '떨어져 앉을 두 사람', '지난 짝과 다시 짝 안 되기', 📌 고정 자리를 지정해요. **🔀 자리 바꾸기**를 누르면 조건을 모두 맞춘 자리가 한 명씩 나타나요. '선생님 쪽에서 / 학생 쪽에서'로 칠판 위치를 바꿔 보고, 🖨️ 인쇄도 돼요.
- **🤝 모둠 활동 동료평가**: '1모둠: 가람, 나래, 다솜'처럼 모둠을 적거나 랜덤 뽑기의 모둠을 불러와요. 평가 기준 3개(고쳐 쓸 수 있음)와 '나 자신도 평가하기(자기평가)'를 정해 📱 학생과 함께하기. 학생은 자기 이름을 고르고, 모둠 친구마다 1~5점과 한마디를 남겨요. **점수와 한마디는 선생님 화면에만** 보이고, 학생별 평균과 엑셀 내려받기가 있어요.
- **📝 생활기록부 문장 도우미**: 행동특성·교과 세특·창체 중 영역과 학생을 고르면, **관찰 기록에 적어 둔 내용**이 옆에 모여요. 기록을 골라 **⬇️ 고른 기록으로 초안 넣기**(끝말은 '~함/~임'으로 맞춰져요)를 누르거나, 🧩 문장 틀을 눌러 넣고 고쳐 써요. 글자 수와 **바이트(한글 3바이트)**가 보이고 제한(예: 1500바이트)을 넘으면 빨갛게 표시돼요. 학생별로 저장되고 엑셀로 내려받아요. **초안**이니 꼭 선생님이 다듬어 주세요.
- **🎙️ 낭독 · 말하기 녹음 과제**: 읽을 글이나 말하기 주제를 적어 📱 학생과 함께하기. 학생은 🔴 녹음 시작 → ⏹ 멈추기 → 들어 보고 → **📤 선생님께 내기**(최대 2분 30초, 다시 녹음해 고쳐 낼 수 있어요). 선생님은 학생별 녹음을 듣고 ★ 별점과 한마디 피드백을 남기면, **그 학생에게만** 자기 피드백이 보여요. 브라우저가 마이크 사용을 물으면 '허용'을 눌러요.

## B-3. 화면을 편하게 쓰는 기능

- **첫 화면**: 위에서부터 **최근 쓴 도구**(이 기기에서 최근에 연 도구 6개) → **9개 묶음 3×3 타일** → **🔍 도구 찾기**(‘자리’, ‘투표’처럼 이름 일부만 쳐도 바로 나와요) 순서예요. 화면 높이에 맞춰 한눈에 다 들어와요. 타일을 누르면 그 묶음의 도구만 펼쳐지고, 도구를 고르면 그 화면으로 가요. 도구를 쓰는 동안 다른 도구는 오른쪽 도구 서랍에서 골라요. 브라우저의 뒤로 가기로 묶음 → 첫 화면으로 돌아와요.

- **⛶ 크게 보기 (TV·전자칠판)**: 메뉴와 단추가 숨고 전체 화면으로 도구만 크게 보여요. 오른쪽 위 **✕ 크게 보기 끝내기**나 Esc로 돌아와요.
- **오른쪽 도구 서랍**: 마우스를 **화면 오른쪽 끝**에 대거나, 태블릿에서 **오른쪽 끝을 왼쪽으로 밀면**(또는 **◀ 도구** 손잡이를 누르면) 모든 도구가 나타나요. 저장하지 않은 내용이 있으면 한 번 더 눌러야 이동해요.
- 컴퓨터·태블릿 화면에서는 만다라트·마인드맵이 **화면 높이에 맞춰** 한눈에 보여요.

# C. 도구별 사용법

## C-1. 깊이 생각하기 — 글의 갈래별로

홈 화면의 '깊이 생각하기'가 **📘 설명하는 글 · 🗣️ 설득하는 글 · 📖 이야기 · 🌸 시 · 🔎 어떤 글에도** 다섯 묶음으로 나뉘어 있어요.

**📘 설명하는 글**
- **🗺️ 글의 짜임 지도**: 짜임(순서·나열·비교와 대조·원인과 결과·문제와 해결)을 고르면 그 모양의 지도가 나와요. 짜임 칸에 내용을 정리하고 문단마다 역할을 붙인 뒤 '글 전체의 중심 생각'을 써요.
- **🪜 질문 사다리**: 사실 질문 → 추론 질문 → 평가·적용 질문 세 단에 질문을 만들고 ⭐ 가장 좋은 질문을 골라요. 선생님 한눈에 보기에 단계별 질문이 모여요.

**🗣️ 설득하는 글**: ⚖️ 주장·근거·이유, 🗣️ 찬반 토론판

**📖 이야기**
- **📈 인물 마음 그래프**: 인물과 사건을 차례로 적고 사건마다 마음 얼굴(😭~😆)과 까닭을 골라요. 꺾은선 그래프로 마음의 오르내림이 보여요. 한눈에 보기에는 반 평균 그래프가 나와요.
- **🎤 인물 인터뷰**: 선생님이 인물을 정해 공유 → 학생은 인물에게 질문을 남기고, **🎭 인물이 되었어요**를 켠 친구가 인물이 되어 대답해요. 👍 공감을 누르고, 선생님은 질문 하나를 **🎤 지금 질문**으로 골라 큰 화면 맨 위에 띄워요.
- **🦸 내가 주인공이라면**: 이야기 속 고민 장면과 선택지를 적어 공유 → 학생은 하나를 고르고 까닭을 써요. 반 전체 선택이 그래프로 나오고 친구들의 까닭이 모여요(이름은 선생님 화면에만).

**🌸 시**
- **🌸 시 감상 카드**: 시를 붙여 넣으면 줄마다 눌러 고를 수 있게 나와요. 마음에 드는 표현을 눌러 고르고 그 까닭, 감각으로 떠올리기(보이는 장면·들리는 소리·느껴지는 것), 시의 마음 날씨와 까닭, 한 행 바꿔 쓰기, 떠오른 내 경험을 써요. 한눈에 보기에 '많이 고른 표현'과 마음 날씨 그래프가 나와요.
- **🎨 시 그림**: 시를 공유하면 학생은 **그림판(색 고르기·🧽 지우개·↶ 되돌리기)**에 그리거나 **종이에 그린 그림을 사진으로 올려** 그 장면이 담긴 시 구절과 함께 내요. 반 갤러리에 모두 모이고 ❤️를 누를 수 있어요. 그림은 크기를 줄여(약 0.7MB 이하) 저장돼요.

**🔎 어떤 글에도**: 🔍 보고·생각하고·궁금해하기, 🔄 생각 바뀜 기록, 🧱 담벼락 등

**기존 도구 사용법**
- **⚖️ 주장·근거·이유**: 탐구 질문을 정해 공유 → 학생은 주장, 근거(최대 3개), 이유, 반론을 쓰고 스스로 점검한 뒤 제출해요.
- **🔍 보고·생각하고·궁금해하기**: 그림(사진·그래프·작품)을 올려 공유 → 보이는 것 → 생각 → 궁금한 것 순서로 써요.
- **🔄 생각 바뀜 기록**: 수업 시작에 '전에는'을 써서 제출, 수업 끝에 '지금은'과 바뀐 까닭을 쓰고 다시 제출해요. 전·후 **확신 정도(1~5)**도 고르게 되어, 학생은 '2 → 5 ⬆ +3'처럼 숫자와 그래프로 변화를 보고, 선생님 한눈에 보기에는 생각이 바뀐 학생 비율, 확신 평균 변화, 바뀐 정도 원그래프, 학생별 변화 그래프가 나와요.
- **🗣️ 찬반 토론판**: 처음 입장 고르기 → 양쪽 근거 붙이기 → 선생님이 **마지막 입장 고르기 열기**를 켜면 다시 골라요. 입장을 바꾼 사람 수가 나와요(이름은 선생님 화면에만).
- **🧱 담벼락**: **'내 생각 + 그 까닭' 형식**을 켜면 까닭을 꼭 쓰게 돼요. 글마다 💬로 ❓질문 · ➕덧붙임 · 👍공감 댓글을 달아요.
  - **템플릿**: 차곡차곡(기본), 자유 배치, 두 칸(찬반), PMI, KWL, 처음·가운데·끝, 마음 날씨, 네 칸, 가운데 주제. 칸 이름은 고쳐 쓸 수 있어요. 배경은 코르크판·칠판·모눈종이·하얀 종이·하늘 중에서 골라요.
  - **메모 옮기기**: '학생은 자기 메모만 / 모두 자유롭게 / 선생님만' 중에서 골라요. 메모를 끌어서 옮기면 모두의 화면에 바로 반영돼요. **🧹 자리 정리**를 누르면 처음 자리로 돌아가요.

**기존 도구에 더한 기능**
- **만다라트**: 모두 채우면 가운데 주제가 크게 빛나요. **⭐ 가장 중요한 칸 3개 고르기**와 고른 까닭 쓰기도 있어요.
- **벤다이어그램**: '그래서 무엇을 알 수 있나요?' 칸과 '가장 중요한 차이점 하나와 그 까닭' 칸이 있어요.
- **KWL 표**: W의 질문마다 ❓아직 → 🤔조금 → ✔풀렸어요로 표시하고, '새로 생긴 질문'을 써요.
- **피시본**: ☆로 가장 중요한 원인을 고르고, **왜? 사다리**로 세 번 파고들어요.
- **실시간 투표**: **고른 까닭도 쓰게 하기**를 켤 수 있어요. 가장 적게 뽑힌 보기는 **🔎 소수 의견**으로 표시돼요.
- **출구 카드**: **✏️ 직접 만들기**를 누르거나 질문 칸을 눌러 선생님이 직접 써요(최대 5개, ＋ 질문 추가). 질문 묶음(기본, 생각 돌아보기, 3-2-1, 마음 돌아보기, 한 문제 확인)을 고른 뒤 고쳐 써도 돼요.
- **워드클라우드**: 모양을 '주제에 맞게 자동'으로 두면 주제 낱말에 따라 하트·별·나무·물방울·집·말풍선·사과·동그라미·구름 모양이 골라져요. 직접 고를 수도 있어요.
- **📒 알림장 글씨 크기**: 미리 보기 오른쪽 '가 크게 / 가 더 크게 / 가 아주 크게'로 고르고 저장하면 학생 화면과 ⛶ 크게 보기에도 같은 크기로 보여요.
- **✨ 반짝 문장 (이야기 지도 → 바른 글씨 쓰기)**: 이야기 지도 맨 아래 '반짝 문장' 칸에 책 속에서 마음에 남은 문장을 3개까지 적어요(쪽수, 누가 한 말, 고른 까닭도 함께). 선생님은 이야기 지도에서 **✍️ 반짝 문장으로 바른 글씨 쓰기 만들기**를 누르면 학생들이 제출한 반짝 문장이 모이고, 고른 문장이 바른 글씨 쓰기 문구로 들어가요. 바른 글씨 쓰기에서 **✨ 이야기 지도의 반짝 문장 가져오기**를 눌러도 저장된 이야기 지도들의 문장을 불러올 수 있어요. 연습 칸 위에는 『책 제목』 쪽수 · 고른 사람이 출처로 표시돼요. 문구는 언제든 선생님이 직접 쓰고 고칠 수 있어요.
- **빙고판**: 줄을 완성할 때마다 '원 빙고! → 투 빙고! → 쓰리 빙고! → 포 빙고!'가 크게 뜨고 소리가 나요. 5줄이면 '🏆 빙고 완성!'과 함께 색종이가 날려요.
- **낱말 카드**: 카드를 뒤집어 뒷면을 볼 때 '띵동' 소리가 나요.
- **소리 켜기/끄기**: 빙고판·낱말 카드·타이머·돌림판·랜덤 뽑기(모둠 짜기 포함)에 **🔊 소리 켬 / 🔇 소리 끔** 단추가 있어요. 누를 때마다 바뀌고, 저장하면 그 상태가 기억돼요.
- **모둠 짜기**: 두구두구 소리 뒤에 이름이 한 명씩 모둠으로 들어가고, 다 짜이면 '짜잔!' 소리가 나요.
- **학습 일지**: '오늘 생각이 바뀐 점', '아직 이해되지 않는 부분' 칸이 있어요.

## C-1-1. ✍️ 글쓰기

세 도구 모두 **📱 학생과 함께하기**로 QR을 띄우면 학생이 각자 기기에서 써요. 쓰는 동안 저절로 저장되고(💾 저장 단추도 있어요), 선생님 화면에 학생별 글 카드와 진행 단계가 모여요.

**글쓰기 과정 (살아 있는 글쓰기 · 독서기록장)** — 다섯 단계를 차례로 거쳐요.
1. ✏️ **처음 쓰기**: 생각나는 대로 끝까지 써요.
2. 🗣️ **소리 내어 읽기**: 글이 문장마다 크게 나와요. 소리 내어 읽다가 어색한 문장을 누르면 🖍️ 표시돼요. '읽으며 살펴봐요' 점검 목록이 있고, 🔊 컴퓨터가 읽어 주기도 돼요. '소리 내어 끝까지 읽었어요'에 체크해야 다음으로 넘어가요.
3. 🖍️ **고쳐 쓰기**: 표시한 문장이 위에 모여 보이고, 처음 쓴 글이 들어 있는 칸에서 고쳐요(내용 중심).
4. 🗣️ **다시 소리 내어 읽기**: 고친 글로 2단계를 한 번 더 해요.
5. ✅ **다시 고쳐 써 완성하기**: 문장·맞춤법·띄어쓰기·문단을 다듬고 **📤 완성한 글 내기**.
- 완성하면 **🔍 처음 쓴 글과 비교해 고친 곳 보기**로 바꾼 말(초록)과 지운 말(빨간 줄)을 볼 수 있어요. '다시 고치기'로 이어서 고칠 수 있어요.

- **🌱 살아 있는 글쓰기**: 날짜 · 주제(글감) · 날씨(그림 고르기 + 날씨를 내 말로) · 제목 · 글. 선생님이 '미리 채워 둘 칸'에 주제를 적으면 학생 화면에 들어가 있어요(학생이 바꿀 수 있어요).
- **📚 독서기록장**: 책 제목 · 지은이 · 출판사 · 출판년도 · 책 읽은 날 · 날씨 · 읽은 쪽(부터~까지) · 쓰는 방법(자유롭게, 느낀 점 중심, 인물에게 편지, 뒷이야기 상상하기, 마음에 남은 문장)을 고르면 그에 맞는 안내가 글 칸에 보여요. 반이 함께 읽는 책이면 책 정보를 미리 채워 둘 수 있어요.
- **🌿 배움이 깃드는 글쓰기** — 칸을 채우는 학습지가 아니라 **한 편의 글**로 써요. 세 단계예요.
  1. 🧺 **생각 모으기**: 수업 전 알고 있던 것(선택) · 수업의 흐름(선택) · **새롭게 알게 된 것 · 내 말로 설명하기 · 아직 궁금하거나 헷갈리는 것(꼭 써요)** · 삶과 잇기(선택)를 낱말이나 짧은 메모로 적어요.
  2. 🧵 **한 편의 글로 엮기**: 모은 메모를 옆에 보며 제목을 붙이고 문단을 이어 써요. **글의 뼈대**(열기 → 수업 이야기 → 깨달음 → 닫기)와 **이어 주는 말** 단추(처음에는, 그런데 오늘, 먼저, 그다음에, 왜냐하면, 아직 … 등)를 누르면 글에 들어가요.
  3. 🗣️ **읽고 고쳐 쓰기**: 소리 내어 읽으며 어색한 문장을 눌러 표시하고, 바로 아래에서 고쳐 써 **📤 완성한 글 내기**.
  - 날짜 · 날씨 · 교과 · 교시 · 학습 목표는 선생님이 미리 채워 둘 수 있어요(**🗓️ 주간학습 안내에서 가져오기**). 선택 메모 칸은 '쓰게 할 칸'에서 끌 수 있어요.
  - 읽는 사람(선생님 · 문집)에게는 제목이 붙은 한 편의 글이 보이고, 메모는 선생님 화면의 **🧺 생각 메모** 탭에서 따로 봐요. 선생님 화면 위쪽에 **❓ 아이들이 아직 궁금해하는 것**이 모여요.

**선생님 기능**
- 📣 안내, 📖 선생님 예시 글(학생 화면에 접어서 보여요)
- 학생 글 카드를 누르면 완성한 글 · 고쳐 쓴 글 · 처음 쓴 글 · 🔍 고친 곳을 볼 수 있고, **💌 도장**(🌟 마음이 담긴 글 등)과 **한마디**를 남기면 그 학생 화면에만 보여요.
- **📚 문집 만들기**: 이 활동의 글 또는 그 도구로 쓴 모든 활동의 글을 모아 학생별·날짜순으로 표지·차례와 함께 인쇄해요. 인쇄 창에서 'PDF로 저장'을 고르면 문집 파일이 돼요.
- 📥 기록 내려받기로 모든 칸과 글(처음·고친·완성)을 엑셀로 받아요.

## C-2. 받아쓰기 · 영어 단어 · 바른 글씨

- **📝 받아쓰기 / 🔤 영어 단어**
  - **✏️ 만들기**: 회차와 문제를 적어요. 여러 줄을 한꺼번에 붙여 넣을 수 있어요(영어는 `give up - 포기하다`).
  - **📢 불러주기**: 🔊로 하나씩 읽거나, **1번부터 차례로 읽기**로 자동으로 읽어요. 간격은 5~30초 중에서 골라요.
  - **✅ 정답 보여주기**: 한 번호씩 크게 보여요. 키보드 ← →로도 넘겨요.
  - 영어는 '영어 듣고 쓰기'와 '뜻 듣고 영어 쓰기' 중에서 골라요.
- **✍️ 바른 글씨 쓰기**
  - 문구를 한 줄에 하나씩 넣어요. '＋ 예시 문구(속담) 넣기' 단추도 있어요.
  - 깍두기 칸에 진한 글씨 → 흐린 따라 쓰기 줄 → 빈 줄이 나와요.
  - **띄어쓰기는 분홍 칸의 빨간 ∨**로 보여요.
  - 태블릿에서는 **✏️ 따라 쓰기**로 손가락·펜으로 쓰고 제출해요. **🖨️ 인쇄**로 종이 학습지도 만들어요.

## C-3. 학급 생활

- **📒 알림장**
  - 알림, 숙제, 준비물, 선생님 한마디를 적어 **⛶ 크게 보기**로 띄우거나, **📋 글로 복사**해 반 SNS에 붙여 넣어요.
  - 학생은 QR로 들어와 항목을 하나씩 체크하고 **✅ 다 확인했어요**를 눌러요. 선생님 화면에 확인한 학생 이름이 모여요.
- **🗓️ 주간학습 안내 · 학급 일정**
  - **주 시작(월)** 날짜를 고르면(◀ ▶, 이번 주) '11월 4주 주간학습 안내 (11.23 ~ 11.27)'처럼 제목이 저절로 붙어요. 금·토·일에 새로 만들면 다음 주로 시작해요.
  - **시간표**: 4~7교시를 고르고 칸마다 과목(누르면 목록이 나와요)과 학습 내용(단원·쪽수)을 적어요. 요일마다 🎒 준비물 칸이 있어요. **📌 과목을 기본 시간표로 기억**해 두면 다음부터 **📋 기본 시간표 넣기**로 과목이 채워져요.
  - **📖 공부 목표 · 🌱 생활 목표**, **📢 가정 알림**, **💬 선생님 한마디**를 적어요.
  - **📆 학급 일정**: `11/25 | 현장체험학습`, 여러 날은 `12/22~12/24 | 학예회 연습`처럼 한 줄에 하나씩 적어요. 그 주 요일 칸 위에 📌로 표시되고, '쉬는 날·휴업일·재량휴업·방학'이 들어가면 그날 칸이 회색이 돼요. 아래에 **다가오는 일정(D-day)**과 **월 달력**이 나와요.
  - **⏭ 다음 주 안내 만들기**: 과목·교시·학급 일정을 이어 받은 다음 주 안내가 새로 열려요(학습 내용·준비물·알림은 비워져요). 채우고 저장하면 주마다 따로 저장 목록에 쌓여요.
  - **📱 학생과 함께하기**로 QR을 띄우면 학생·가정이 휴대폰으로 봐요(휴대폰에서는 요일별 카드로 보여요). '✅ 확인했어요'를 누른 사람이 선생님 화면에 모여요. **📋 글로 복사**로 반 SNS에 붙여 넣고, **🖨️ 인쇄**는 A4 가로로 나와요.
- **🧘 명상**
  - 1·3·5·10분과 호흡법을 골라 **▶ 명상 시작**을 눌러요.
  - 음악은 위키미디어 공용의 자유 이용 녹음 49곡(🌙 잔잔한 곡 38 · ☀️ 밝고 경쾌한 곡 11, 생상스 〈백조〉 등 첼로·바이올린 곡 포함)이에요. **곡 이름을 누르면 그 곡만 한 번 들려주고 끝나요.** '▶ 목록 이어 듣기'는 체크한 곡들을 차례로 들려줘요. 곡마다 체크하거나 '전체 선택·전체 해제·잔잔한 곡만·밝은 곡만' 버튼으로 틀 곡을 골라요. 진행 바를 누르면 원하는 곳으로 건너뛰어요. 출처는 앱 안 '음원 출처와 이용 허락'에 있어요.
  - 음악은 인터넷으로 불러와요.

# D. 문제 해결

| 이렇게 보이면 | 까닭 | 이렇게 해요 |
|---|---|---|
| `404 DEPLOYMENT_NOT_FOUND` | 주소가 틀렸거나 배포가 없거나 지워짐 | Vercel 대시보드 → 프로젝트 → **Visit**으로 들어가요. 주소를 직접 쳤다면 대시보드의 주소와 같은지 봐요 |
| Vercel에 **No Production Deployment** | 배포가 한 번도 성공하지 않음 | 프로젝트를 지우고 Vercel Drop으로 다시 올려요. GitHub 방식이면 저장소 맨 위에 `index.html`이 있는지 봐요 |
| `auth/unauthorized-domain` | 앱 주소가 Firebase 승인된 도메인에 없음 | **A-3** 대로 주소를 추가하고 1~2분 뒤 새로고침해요 |
| `auth/operation-not-allowed` | Google(또는 익명) 로그인이 꺼져 있음 | **A-1의 4번** 대로 Google과 익명을 켜요. 지원 이메일도 골라요 |
| **선생님 로그인** 단추가 없고 '이 기기에 저장'만 보임 | `index.html`에 설정값이 없거나 익명 로그인이 꺼짐 | 설정값을 넣은 파일로 다시 올리고, 익명 로그인을 켜요 |
| 저장할 때 **'저장하지 못했어요'** | Firestore를 안 만들었거나 규칙이 안 맞음 | **A-1의 5~6번**을 확인해요. 이메일 목록 규칙을 켰다면 내 이메일이 들어 있는지 봐요 |
| 카카오톡에서 로그인 안 됨 | 카카오톡 안 브라우저 제한 | **다른 브라우저로 열기** |
| 녹음이 안 됨 | 마이크 허용을 안 눌렀거나, 카카오톡 안 브라우저 | 주소창의 🔒(자물쇠) → 마이크 허용. 크롬·사파리로 열어요 |
| 명상 음악이 안 나옴 | 인터넷 연결 문제 | 교실 인터넷을 확인해요. 숨쉬기 안내는 음악 없이도 돼요 |

## 알아 두면 좋은 점

- 무료 요금제(Spark) 하루 한도(읽기 5만, 쓰기 2만 회)는 한 반 30명이 매일 써도 넉넉해요.
- 학생 응답에는 학생이 적은 이름이 저장돼요. 실명 대신 번호나 별명을 써도 돼요.
- 활동을 지우면(저장 목록 → 삭제) 그 활동의 학생 응답도 함께 지워져요.
- 올린 그림은 크기를 줄여(최대 약 600KB) 활동과 함께 저장돼요.
- 낭독 녹음은 작은 크기(약 2분 30초에 1MB 이하)로 학생 응답에 저장되고, 선생님 피드백은 활동 기록에 저장돼요. 동료평가 점수와 한마디는 학생 화면에 보이지 않아요.
- 자리 바꾸기·역할표·발표 기록·생활기록부 초안은 선생님 계정에만 저장돼요(학생에게 공유되지 않아요).
