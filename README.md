# 우리 반 학습도구 — 설치·배포 안내

한 파일(`index.html`)로 된 웹앱이에요. 학습도구 28개가 들어 있고, 모든 도구에 저장 기능이 있어요.
Firebase(Firestore)에 저장하고 Vercel에 올리면, 학생들이 로그인 없이 QR로 들어와 참여할 수 있어요.

| 묶음 | 도구 | 학생과 함께할 때 |
|---|---|---|
| 생각 정리 | 만다라트, 마인드맵, 벤다이어그램, KWL 표, 피시본, 이야기 지도 | 학생이 각자 채워서 **제출** → 선생님이 제출물 확인 |
| 깊이 생각하기 | 주장·근거·이유, 보고·생각하고·궁금해하기, 생각 바뀜 기록, 찬반 토론판 | 제출물 **한눈에 보기** 표 / 토론판은 실시간 |
| 수업 참여 | 실시간 투표, 출구 카드, 생각 온도계, 워드클라우드, 담벼락 | 학생 응답이 선생님 화면에 **실시간**으로 모임 |
| 모둠 활동 | 랜덤 뽑기·모둠 짜기, 돌림판, 타이머 | 교사 화면용 (설정만 저장) |
| 받아쓰기 · 바른 글씨 | 받아쓰기(회차당 10문제), 영어 단어·구동사(회차당 15개), 바른 글씨 쓰기 | 받아쓰기는 교사 화면용 / 바른 글씨는 학생이 태블릿에 따라 쓰고 제출 |
| 정리·복습 | 낱말 카드, 빙고판, 순서 맞추기 | 학생이 각자 공부·풀이 (빙고·순서는 제출 가능) |
| 기록·평가 | 학습 일지, 루브릭 자기평가 | 학생이 각자 작성해서 **제출** |
| 학급 생활 | 알림장, 명상 | 알림장은 학생이 QR로 보고 체크 · ‘다 확인했어요’ / 명상은 교사 화면 |

## 1. Firebase 준비 (처음 한 번, 약 10분)

1. **프로젝트 만들기**: [Firebase 콘솔](https://console.firebase.google.com)에서 새 프로젝트를 만들어요 (기존 프로젝트를 써도 돼요).
2. **웹 앱 추가**: 프로젝트 설정(⚙️) → 일반 → 내 앱 → 웹(`</>`) 추가 → 나오는 `firebaseConfig` 값을 복사해요.
3. **설정값 붙여 넣기**: `index.html`을 열어 위쪽의 `window.FIREBASE_CONFIG = { ... }` 칸에 붙여 넣어요.
   (이 값은 공개되어도 괜찮은 값이에요. 실제 보호는 아래 보안 규칙이 해요.)
4. **로그인 방법 켜기**: Authentication → 로그인 방법(Sign-in method)에서
   - **익명(Anonymous)** 사용 설정 ← 학생용
   - **Google** 사용 설정 ← 선생님용
5. **Firestore 만들기**: Firestore Database → 데이터베이스 만들기 → 위치는 `asia-northeast3 (서울)` 추천 → 프로덕션 모드.
6. **보안 규칙 붙여 넣기**: Firestore → 규칙 탭에 `firestore.rules` 내용을 통째로 붙여 넣고 **게시**.
   - 다른 Google 계정이 선생님으로 쓰지 못하게 하려면, 규칙 안의 `// && request.auth.token.email in [...]` 줄의 `//`를 지우고 선생님 이메일을 적어요.

## 2. Vercel에 올리기

- **GitHub 사용**: 새 저장소에 `index.html`을 올리고 → Vercel에서 *Add New → Project*로 그 저장소를 가져오면 끝이에요 (빌드 설정 필요 없음).
- **CLI 사용**: `index.html`이 있는 폴더에서 `npx vercel --prod`.

올린 뒤 **꼭** 해야 할 일:
Firebase 콘솔 → Authentication → 설정 → **승인된 도메인**에 Vercel 주소(예: `our-class-tools.vercel.app`)를 추가해요. 안 하면 선생님 Google 로그인이 막혀요.

## 3. 수업에서 쓰는 순서

1. 선생님은 오른쪽 위 **선생님 로그인**(Google)으로 들어가요.
2. 도구를 골라 내용을 만들고 **저장** → 다음에도 **저장 목록**에서 열 수 있어요.
3. **📱 학생과 함께하기** → QR이 나와요. **크게 띄우기**로 TV에 띄우면 학생들이 카메라로 찍고 들어와요.
4. 학생은 위쪽에 **이름(번호)** 을 적고 참여해요.
   - 투표·온도계·출구 카드·담벼락·워드클라우드: 누르는 즉시 선생님 화면에 모여요.
   - 만다라트 같은 개별 활동: 다 쓰고 **선생님께 제출하기** → 선생님은 **제출물 (n)** 에서 한 명씩 열어 봐요.
   - 학생이 쓰던 내용은 학생 기기에 자동 보관돼서, 창을 닫았다 열어도 이어서 쓸 수 있어요.
5. 투표·생각 온도계는 **학생 화면에도 결과 보여 주기**를 켜면 학생들도 결과를 볼 수 있어요.

학생이 첫 화면 주소로 들어오면 모든 도구를 자유롭게 쓸 수 있어요 (이때 저장은 그 기기에만 돼요).

**TV·전자칠판에 띄울 때**: 도구 위쪽의 **⛶ 크게 보기**를 누르면 메뉴와 단추가 숨고 전체 화면으로 도구만 크게 보여요. 오른쪽 위 **✕ 크게 보기 끝내기**나 Esc로 돌아와요.

## 4. 깊이 생각하기 도구 쓰는 법

- **⚖️ 주장·근거·이유**: 선생님이 탐구 질문을 정해 공유 → 학생은 주장, 근거(최대 3개), 이유, 반론까지 쓰고 스스로 점검한 뒤 제출. 제출물에서 학생들의 주장을 표로 한눈에 봐요.
- **🔍 보고·생각하고·궁금해하기**: 선생님이 그림(사진·그래프·작품)을 올려 공유 → 학생은 보이는 것 → 생각 → 궁금한 것 순서로 써요. ‘궁금한 것’ 모음은 다음 차시 탐구 질문으로 쓰기 좋아요.
- **🔄 생각 바뀜 기록**: 수업 시작 때 ‘전에는’을 쓰고 제출, 수업 끝에 ‘지금은’과 바뀐 까닭을 쓰고 다시 제출해요. 한눈에 보기 표에서 반 전체의 전·후 생각을 비교해요.
- **🗣️ 찬반 토론판**: ① 학생들이 처음 입장 고르기 → ② 양쪽 근거를 붙이고 함께 읽기 → ③ 선생님이 ‘마지막 입장 고르기 열기’를 켜면 다시 고르기. 처음·마지막 입장 그래프와 입장을 바꾼 사람 수가 나와요 (이름은 선생님 화면에만).
- **🧱 담벼락**: ‘내 생각 + 그 까닭’ 형식을 켜면 까닭을 꼭 쓰게 돼요. 글마다 💬 로 ❓질문 · ➕덧붙임 · 👍공감 댓글을 달 수 있어요.

### 기존 도구에 더한 깊이 생각하기 기능
- **만다라트**: 다 채운 뒤 **⭐ 가장 중요한 칸 3개 고르기** → 고른 까닭 쓰기 (넓게 생각하고 → 골라내기).
- **벤다이어그램**: **그래서 무엇을 알 수 있나요?** 와 **가장 중요한 차이점 하나와 그 까닭** 칸.
- **KWL 표**: W에 쓴 질문이 자동으로 목록이 되고, 수업 끝에 ❓아직 → 🤔조금 → ✔풀렸어요 로 표시 + **새로 생긴 질문** 칸.
- **피시본**: 갈래의 ☆로 **가장 중요한 원인**을 고르고, **왜? 사다리**(왜 1·2·3)로 파고든 뒤 해결 방법 쓰기.
- **실시간 투표**: **고른 까닭도 쓰게 하기**를 켜면 까닭을 써야 투표돼요. 결과 아래 **까닭 모아 보기**에서 가장 적게 고른 보기는 **🔎 소수 의견**으로 표시돼요.
- **출구 카드**: 질문 묶음 단추 — 기본 / 🔄 생각 돌아보기(생각이 바뀐 점·아직 모르는 것·어디에 쓸까) / 3-2-1.
- **학습 일지**: **오늘 생각이 바뀐 점**, **아직 이해되지 않는 부분** 칸.

## 5. 받아쓰기 · 영어 단어

- **✏️ 만들기**: 회차 번호와 문제를 적어요. 여러 줄을 한꺼번에 붙여 넣을 수 있어요 (앞 번호는 자동으로 빠지고, 영어는 `give up - 포기하다`처럼).
- **📢 불러주기**: 1~10번(영어는 1~15번)이 크게 스크롤로 보여요. 🔊로 하나씩 읽거나, **1번부터 차례로 읽기**로 “1번, 문장, (다시 한 번)” 순서로 자동으로 읽어 줘요. 사이 간격은 5~30초 중에서 골라요.
- **✅ 정답 보여주기**: 채점할 때 한 번호씩 크게 보여 줘요. 다음/이전, 번호 단추, 키보드 ← → 로 넘기고, **전체 화면**으로 TV에 띄워요.
- 영어는 **영어 듣고 쓰기**(영어를 읽어 줌)와 **뜻 듣고 영어 쓰기**(뜻을 읽어 줌) 중에서 골라요.
- 회차마다 **저장**해 두면 저장 목록에 “12회 받아쓰기”처럼 쌓여요.
- 자동 읽기 목소리는 기기 브라우저의 음성을 써요. 교실 PC 크롬이나 엣지에서 가장 자연스러워요.

## 6. 알림장 · 바른 글씨 · 명상

- **📒 알림장**: 날짜와 알림·숙제·준비물·선생님 한마디를 적으면 공책 모양 알림장이 만들어져요. **⛶ 크게 보기**로 TV에 띄우고, **📋 글로 복사**로 반 SNS에 붙여 넣을 수 있어요. QR로 들어온 학생은 항목을 하나씩 체크하고 **✅ 다 확인했어요**를 누르면, 선생님 화면에 확인한 학생 이름이 모여요. 날짜별로 저장하면 지난 알림장도 저장 목록에서 다시 볼 수 있어요.
- **✍️ 바른 글씨 쓰기**: 선생님이 문구를 한 줄에 하나씩 넣어요(＋예시 속담 넣기도 있어요). 깍두기 칸에 진한 글씨 → 흐린 따라 쓰기 줄 → 빈 줄이 나와요. **띄어 쓰는 자리는 분홍 칸에 빨간 ∨**로 표시되고, 위쪽 큰 글씨에도 ∨가 보여요. 줄 첫머리의 띄어쓰기는 원고지처럼 생략돼요. 태블릿에서 **✏️ 따라 쓰기**를 누르면 손가락·펜으로 칸 위에 직접 쓰고(펜을 쓰면 손바닥이 닿아도 괜찮아요) 제출할 수 있어요. **🖨️ 인쇄**로 종이 학습지도 만들 수 있어요.
- **🧘 명상**: 1·3·5·10분과 호흡법(4-2-6 / 네모 호흡 / 저학년용 3-3)을 고르고 **▶ 명상 시작**. 커졌다 작아지는 원을 따라 숨을 쉬고, 끝나면 종소리와 함께 음악이 천천히 줄어들어요. 음악은 위키미디어 공용의 자유 이용 녹음 10곡(바흐 3, 모차르트 1, 베토벤 2, 슈만 3, 라흐마니노프 1)이고, 곡마다 넣고 빼기·섞어 듣기·소리 크기를 정할 수 있어요. 출처는 ‘음원 출처와 이용 허락’에 있어요. 음악은 인터넷으로 불러오니 교실 인터넷 연결이 필요해요.

## 7. 다른 도구로 빠르게 옮겨 가기

도구를 쓰다가 **마우스를 화면 오른쪽 끝에 대거나**, 태블릿에서 **오른쪽 끝을 손가락으로 왼쪽으로 밀면**(또는 오른쪽 가운데 **◀ 도구** 손잡이를 누르면) 모든 도구가 색깔별로 나타나요. 저장하지 않은 내용이 있으면 한 번 더 눌러야 이동해요.

## 8. 알아 두면 좋은 점

- Firebase 설정값이 비어 있으면 **이 기기(브라우저)에만 저장되는 모드**로 열려요. 미리 써 보기에 좋아요.
- 무료 요금제(Spark)의 하루 한도(읽기 5만, 쓰기 2만 회)는 한 반 30명이 매일 써도 넉넉해요.
- 학생 응답에는 학생이 적은 이름이 저장돼요. 실명 대신 번호나 별명을 쓰게 해도 돼요.
- 활동을 지우면(저장 목록 → 삭제) 그 활동의 학생 응답도 함께 지워져요.
- 올린 그림은 크기를 줄여(최대 약 600KB) 활동과 함께 저장돼요.
