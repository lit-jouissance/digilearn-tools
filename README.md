# 우리 반 학습도구 — 설치 · 사용 안내

한 파일(`index.html`)로 된 수업용 웹앱이에요. 학습도구 **28개**가 들어 있고, **모든 도구에 저장 기능**이 있어요.
Firebase에 저장하고 Vercel에 올리면, 선생님은 Google 계정으로 로그인해 자기 활동을 관리하고, 학생들은 **로그인 없이 QR로** 들어와 참여해요.

- 예시 주소: `https://digilearn-tools.vercel.app`
- 이 안내서는 **A. 처음 설치(관리하는 선생님)** → **B. 선생님 사용법** → **C. 도구별 사용법** → **D. 문제 해결** 순서예요.
- 다른 선생님께는 **B**부터 보여 드리면 돼요.

| 묶음 | 도구 | 학생과 함께할 때 |
|---|---|---|
| 🧩 생각 정리 | 만다라트, 마인드맵, 벤다이어그램, KWL 표, 피시본, 이야기 지도 | 학생이 각자 채워서 **제출** → 선생님이 제출물 확인 |
| 💡 깊이 생각하기 | 주장·근거·이유, 보고·생각하고·궁금해하기, 생각 바뀜 기록, 찬반 토론판 | 제출물 **한눈에 보기** 표 / 토론판은 실시간 |
| 📡 수업 참여 | 실시간 투표, 출구 카드, 생각 온도계, 워드클라우드, 담벼락 | 학생 응답이 선생님 화면에 **실시간**으로 모임 |
| 👥 모둠 활동 | 랜덤 뽑기·모둠 짜기, 돌림판, 타이머 | 교사 화면용 (설정만 저장) |
| 📝 받아쓰기 · 바른 글씨 | 받아쓰기(회차당 10문제), 영어 단어·구동사(회차당 15개), 바른 글씨 쓰기 | 받아쓰기는 교사 화면용 / 바른 글씨는 학생이 따라 쓰고 제출 |
| 🔁 정리 · 복습 | 낱말 카드, 빙고판, 순서 맞추기 | 학생이 각자 공부·풀이 (빙고·순서는 제출 가능) |
| 📒 기록 · 평가 | 학습 일지, 루브릭 자기평가 | 학생이 각자 작성해서 **제출** |
| 🏫 학급 생활 | 알림장, 명상 | 알림장은 학생이 QR로 보고 체크 / 명상은 교사 화면 |

# A. 처음 설치 (관리하는 선생님, 한 번만)

## A-1. Firebase 준비 (약 10분)

1. **프로젝트 만들기**: [Firebase 콘솔](https://console.firebase.google.com)에서 새 프로젝트를 만들어요. 기존 프로젝트를 써도 돼요.
2. **웹 앱 추가**: 프로젝트 설정(⚙️) → 일반 → 내 앱 → 웹(`</>`) 추가 → 나오는 `firebaseConfig` 값을 복사해요.
3. **설정값 붙여 넣기**: `index.html`을 메모장이나 VS Code로 열어, 위쪽 `window.FIREBASE_CONFIG = { ... }` 칸에 붙여 넣고 저장해요.
   - 이 값은 공개되어도 괜찮은 값이에요. 실제 보호는 보안 규칙(A-1의 6번)이 해요.
   - ⚠️ 새 `index.html`을 받을 때마다 이 설정값을 **다시 넣어야** 해요.
4. **로그인 방법 켜기**: 왼쪽 **Authentication(인증)** → 위쪽 **Sign-in method(로그인 방법)** 탭 → **Add new provider(새 제공업체 추가)**
   - **Google** → **Enable(사용 설정)** 켜기 → **Project support email(프로젝트 지원 이메일)**에서 내 Gmail 고르기 → **Save** ← 선생님용
   - **Anonymous(익명)** → **Enable** 켜기 → **Save** ← 학생용
   - 프로젝트 지원 이메일은 로그인 창에 보이는 **연락처일 뿐**이에요. 여기에 내 이메일을 넣어도 다른 선생님들은 그대로 로그인할 수 있어요.
5. **Firestore 만들기**: **Firestore Database** → 데이터베이스 만들기 → 위치 `asia-northeast3 (서울)` 추천 → 프로덕션 모드.
6. **보안 규칙 붙여 넣기**: Firestore → **규칙** 탭에 `firestore.rules` 내용을 통째로 붙여 넣고 **게시**해요.

### 누가 '선생님'으로 쓸 수 있게 할까요?

- **기본(그대로 두기)**: Google 계정이 있는 선생님이면 **누구나** 로그인해서 저장·공유할 수 있어요. 다른 학교·학년 선생님들과 나눠 쓰기에 좋아요.
- **정한 선생님만**: `firestore.rules` 안의 아래 줄에서 `//`를 지우고 이메일을 적은 뒤 **게시**해요. 목록에 없는 사람은 로그인은 되지만 저장·공유가 막혀요.

  ```
  && request.auth.token.email in ['moon@gmail.com', 'kim@gmail.com', 'lee@gmail.com']
  ```

  새 선생님이 오시면 이 목록에 이메일을 더하고 다시 **게시**하면 돼요.

## A-2. Vercel에 올리기

### 방법 1. Vercel Drop (가장 쉬움, GitHub 필요 없음)

1. 바탕화면에 폴더(예: `digilearn-tools`)를 만들고, **설정값을 넣은** `index.html`을 넣어요.
2. 로그인한 상태로 **vercel.com/drop**에 들어가요.
3. 폴더(또는 `index.html` 파일 하나)를 화면에 끌어다 놓아요.
4. 팀(Hobby)을 고르고 프로젝트 이름(예: `digilearn-tools`)을 적은 뒤 **Deploy**를 눌러요.
5. 완료 화면의 주소(**Visit**)를 눌러 첫 화면이 열리는지 확인해요.

**앱을 고쳐 다시 올릴 때**: 드롭할 때마다 새 프로젝트가 만들어져요. 같은 주소를 유지하려면 이렇게 해요.
1. Vercel 대시보드에서 기존 프로젝트 → **Settings** → 맨 아래 **Delete Project**로 지워요.
2. 새 `index.html`(설정값 넣은 것)을 **같은 이름**으로 다시 드롭해요.

저장한 활동과 학생 응답은 Firebase에 있어서 다시 올려도 그대로 남아요.

### 방법 2. GitHub + Vercel (자주 고칠 때 추천)

1. github.com → **＋ → New repository** → 이름(예: `digilearn-tools`) → **Create repository**를 눌러요.
2. **Add file → Upload files** → `index.html`을 끌어다 놓고 **Commit changes**를 눌러요. 파일은 폴더 안이 아니라 **맨 위**에 있어야 해요.
3. vercel.com → **Add New → Project** → 그 저장소 **Import** → Framework Preset **Other** → **Deploy**를 눌러요.
4. 고칠 때는 GitHub에 새 `index.html`을 같은 이름으로 올리고 **Commit**만 하면, 같은 주소로 자동 반영돼요.

## A-3. Firebase에 앱 주소 등록 (꼭!)

Firebase 콘솔 → **Authentication** → **Settings(설정)** 탭 → **Authorized domains(승인된 도메인)** → **Add domain(도메인 추가)**
- `digilearn-tools.vercel.app`처럼 **`https://`와 끝의 `/`를 뺀 주소**만 적어요.
- 안 하면 선생님 로그인 때 `auth/unauthorized-domain` 오류가 나요.

## A-4. 설치 확인

1. 앱 주소에 들어가 오른쪽 위 **선생님 로그인**을 눌러요.
2. 오른쪽 위가 **'선생님 · 내 이메일'**로 바뀌는지 봐요.
3. 아무 도구에서나 **저장**을 눌러 **'저장됨'**이 뜨는지 봐요.
4. **📱 학생과 함께하기**로 QR을 띄우고 휴대폰으로 찍어 학생 화면이 열리는지 봐요.

# B. 선생님 사용법 (다른 선생님께 이 부분을 알려 주세요)

## B-1. 내 계정으로 로그인하기

1. 앱 주소를 **크롬, 엣지, 사파리**로 열어요.
2. 오른쪽 위 **선생님 로그인** → 내 Google 계정을 골라요.
3. 오른쪽 위가 **'선생님 · 내 이메일'**로 바뀌면 끝이에요.

- 선생님마다 **저장 목록이 따로**예요. 다른 선생님의 활동이나 그 반 학생 응답은 서로 보이지 않아요.
- 같은 계정으로 로그인하면 **집 컴퓨터, 교실 PC, 태블릿 어디서든** 내 저장 목록을 열 수 있어요.
- 여러 사람이 쓰는 교실 PC라면 수업 뒤 **로그아웃**을 눌러 주세요.
- 로그인하지 않으면 오른쪽 위에 **'이 기기에 저장'**이 보이고, 그 브라우저에만 저장돼요. 로그인해도 계정으로 자동으로 옮겨지지 않으니 **처음부터 로그인하고** 쓰세요.

### 로그인이 안 될 때
- **카카오톡에서 링크를 열었을 때**: 카카오톡 안 브라우저에서는 Google 로그인이 막혀요. **⋮ → 다른 브라우저로 열기**를 눌러요.
- **아무 창도 안 뜰 때**: 팝업이 차단된 거예요. 주소창 오른쪽 팝업 차단 표시를 눌러 **허용**해요.
- **학교·교육청 Google 계정**: 외부 앱 로그인이 제한된 경우가 있어요. 개인 Gmail로 로그인해요.
- 오류 코드가 보이면 **D. 문제 해결**을 봐요.

## B-2. 수업에서 쓰는 순서

1. **첫 화면**에서 묶음 색깔별로 도구를 골라요.
2. 내용을 만들고 **저장** → 다음에도 **저장 목록**에서 열 수 있어요.
3. **📱 학생과 함께하기** → QR이 나와요. **크게 띄우기**로 TV에 띄우면 학생들이 카메라로 찍고 들어와요. 활동을 고친 뒤에는 **저장**해야 학생 화면에도 반영돼요.
4. 학생은 위쪽에 **이름(번호)**을 적고 참여해요.
   - 투표·온도계·출구 카드·담벼락·워드클라우드·토론판: 누르는 즉시 선생님 화면에 모여요.
   - 만다라트 같은 개별 활동: 다 쓰고 **선생님께 제출하기** → 선생님은 **제출물 (n)**에서 한 명씩 열어 봐요. 일부 도구는 **한눈에 보기** 표도 나와요.
   - 학생이 쓰던 내용은 학생 기기에 자동 보관돼요.
5. 투표·생각 온도계는 **학생 화면에도 결과 보여 주기**를 켜면 학생들도 결과를 봐요.

## B-3. 화면을 편하게 쓰는 기능

- **⛶ 크게 보기 (TV·전자칠판)**: 메뉴와 단추가 숨고 전체 화면으로 도구만 크게 보여요. 오른쪽 위 **✕ 크게 보기 끝내기**나 Esc로 돌아와요.
- **오른쪽 도구 서랍**: 마우스를 **화면 오른쪽 끝**에 대거나, 태블릿에서 **오른쪽 끝을 왼쪽으로 밀면**(또는 **◀ 도구** 손잡이를 누르면) 모든 도구가 나타나요. 저장하지 않은 내용이 있으면 한 번 더 눌러야 이동해요.
- 컴퓨터·태블릿 화면에서는 만다라트·마인드맵이 **화면 높이에 맞춰** 한눈에 보여요.

# C. 도구별 사용법

## C-1. 깊이 생각하기

- **⚖️ 주장·근거·이유**: 탐구 질문을 정해 공유 → 학생은 주장, 근거(최대 3개), 이유, 반론을 쓰고 스스로 점검한 뒤 제출해요.
- **🔍 보고·생각하고·궁금해하기**: 그림(사진·그래프·작품)을 올려 공유 → 보이는 것 → 생각 → 궁금한 것 순서로 써요.
- **🔄 생각 바뀜 기록**: 수업 시작에 '전에는'을 써서 제출, 수업 끝에 '지금은'과 바뀐 까닭을 쓰고 다시 제출해요. 한눈에 보기 표로 전후를 비교해요.
- **🗣️ 찬반 토론판**: 처음 입장 고르기 → 양쪽 근거 붙이기 → 선생님이 **마지막 입장 고르기 열기**를 켜면 다시 골라요. 입장을 바꾼 사람 수가 나와요(이름은 선생님 화면에만).
- **🧱 담벼락**: **'내 생각 + 그 까닭' 형식**을 켜면 까닭을 꼭 쓰게 돼요. 글마다 💬로 ❓질문 · ➕덧붙임 · 👍공감 댓글을 달아요.

**기존 도구에 더한 기능**
- **만다라트**: 모두 채우면 가운데 주제가 크게 빛나요. **⭐ 가장 중요한 칸 3개 고르기**와 고른 까닭 쓰기도 있어요.
- **벤다이어그램**: '그래서 무엇을 알 수 있나요?' 칸과 '가장 중요한 차이점 하나와 그 까닭' 칸이 있어요.
- **KWL 표**: W의 질문마다 ❓아직 → 🤔조금 → ✔풀렸어요로 표시하고, '새로 생긴 질문'을 써요.
- **피시본**: ☆로 가장 중요한 원인을 고르고, **왜? 사다리**로 세 번 파고들어요.
- **실시간 투표**: **고른 까닭도 쓰게 하기**를 켤 수 있어요. 가장 적게 뽑힌 보기는 **🔎 소수 의견**으로 표시돼요.
- **출구 카드**: 질문 묶음 단추로 '기본', '🔄 생각 돌아보기', '3-2-1' 중 하나를 골라요.
- **학습 일지**: '오늘 생각이 바뀐 점', '아직 이해되지 않는 부분' 칸이 있어요.

## C-2. 받아쓰기 · 영어 단어 · 바른 글씨

- **📝 받아쓰기 / 🔤 영어 단어**
  - **✏️ 만들기**: 회차와 문제를 적어요. 여러 줄을 한꺼번에 붙여 넣을 수 있어요(영어는 `give up - 포기하다`).
  - **📢 불러주기**: 🔊로 하나씩 읽거나, **1번부터 차례로 읽기**로 자동으로 읽어요. 간격은 5~30초 중에서 골라요.
  - **✅ 정답 보여주기**: 한 번호씩 크게 보여요. 키보드 ← →로도 넘겨요.
  - 영어는 '영어 듣고 쓰기'와 '뜻 듣고 영어 쓰기' 중에서 골라요.
- **✍️ 바른 글씨 쓰기**
  - 문구를 한 줄에 하나씩 넣어요. '＋ 예시 문구(속담) 넣기' 단추도 있어요.
  - 깍두기 칸에 진한 글씨 → 흐린 따라 쓰기 줄 → 빈 줄이 나와요.
  - **띄어쓰기는 분홍 칸의 빨간 ∨**로 보여요.
  - 태블릿에서는 **✏️ 따라 쓰기**로 손가락·펜으로 쓰고 제출해요. **🖨️ 인쇄**로 종이 학습지도 만들어요.

## C-3. 학급 생활

- **📒 알림장**
  - 알림, 숙제, 준비물, 선생님 한마디를 적어 **⛶ 크게 보기**로 띄우거나, **📋 글로 복사**해 반 SNS에 붙여 넣어요.
  - 학생은 QR로 들어와 항목을 하나씩 체크하고 **✅ 다 확인했어요**를 눌러요. 선생님 화면에 확인한 학생 이름이 모여요.
- **🧘 명상**
  - 1·3·5·10분과 호흡법을 골라 **▶ 명상 시작**을 눌러요.

# D. 문제 해결

| 이렇게 보이면 | 까닭 | 이렇게 해요 |
|---|---|---|
| `404 DEPLOYMENT_NOT_FOUND` | 주소가 틀렸거나 배포가 없거나 지워짐 | Vercel 대시보드 → 프로젝트 → **Visit**으로 들어가요. 주소를 직접 쳤다면 대시보드의 주소와 같은지 봐요 |
| Vercel에 **No Production Deployment** | 배포가 한 번도 성공하지 않음 | 프로젝트를 지우고 Vercel Drop으로 다시 올려요. GitHub 방식이면 저장소 맨 위에 `index.html`이 있는지 봐요 |
| `auth/unauthorized-domain` | 앱 주소가 Firebase 승인된 도메인에 없음 | **A-3** 대로 주소를 추가하고 1~2분 뒤 새로고침해요 |
| `auth/operation-not-allowed` | Google(또는 익명) 로그인이 꺼져 있음 | **A-1의 4번** 대로 Google과 익명을 켜요. 지원 이메일도 골라요 |
| **선생님 로그인** 단추가 없고 '이 기기에 저장'만 보임 | `index.html`에 설정값이 없거나 익명 로그인이 꺼짐 | 설정값을 넣은 파일로 다시 올리고, 익명 로그인을 켜요 |
| 저장할 때 **'저장하지 못했어요'** | Firestore를 안 만들었거나 규칙이 안 맞음 | **A-1의 5~6번**을 확인해요. 이메일 목록 규칙을 켰다면 내 이메일이 들어 있는지 봐요 |
| 카카오톡에서 로그인 안 됨 | 카카오톡 안 브라우저 제한 | **다른 브라우저로 열기** |
| 명상 음악이 안 나옴 | 인터넷 연결 문제 | 교실 인터넷을 확인해요. 숨쉬기 안내는 음악 없이도 돼요 |
